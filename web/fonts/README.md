# Fonts

Saved once from Google Fonts (13 Oct 2026, latin subset) and built into the page by `page.py`, so Toolbelt never
contacts the internet for fonts. All three are free under the SIL Open Font License 1.1.

- `figtree.woff2`: Figtree, weights 400 to 800 (body text)
- `silkscreen-400.woff2`, `silkscreen-700.woff2`: Silkscreen (pixel headings in the Cartridge look)
- `jetbrains-mono-500.woff2`: JetBrains Mono (codes, paths, hashes)
